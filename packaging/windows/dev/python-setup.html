Программе не хватает одной вещи

На этом компьютере нет Python — это бесплатная программа, на которой работает расшифровщик. Установить нужно один раз, дальше она больше никогда о себе не напомнит.

  1. Откройте сайт python.org

    Ссылка: python.org/downloads. Большая жёлтая кнопка сверху — нажмите её, файл начнёт скачиваться.

  2. Запустите скачанный файл

    Он лежит в папке «Загрузки», называется примерно python-3.x.x-amd64.exe. Двойной клик.

    Самое важное. На первом же экране, внизу, есть галочка Add python.exe to PATH — поставьте её до того, как нажмёте кнопку установки. Без этой галочки программа Python не найдёт, и всё придётся делать заново.

  3. Нажмите «Install Now» и дождитесь конца

    Появится полоска загрузки. Когда напишет «Setup was successful» — закройте окно кнопкой Close.

  4. Поставьте библиотеки программы

    Сама программа их больше не ставит: в установщике они уже внутри, а при запуске из исходников их ставят один раз вручную. Откройте командную строку в корневой папке программы (там, где лежит pyproject.toml) и выполните pip install -e . Это займёт несколько минут и потребует интернета.

  5. Запустите «run.bat» ещё раз

    Тот же двойной клик, что и в прошлый раз. Откроется окно подготовки, а затем собственное окно программы. При первом запуске программа загрузит модели распознавания, поэтому ей понадобится интернет.

Если после установки всё равно не работает — скорее всего не поставилась та самая галочка на втором шаге. Запустите установщик Python ещё раз, выберите «Modify» и пройдите заново, следя за ней.
